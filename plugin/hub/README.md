# hub —— 跨会话持久（本插件唯一可变状态）

装插件时**不改安装目录**（升级不丢数据）；状态落用户目录：

```
~/.dsh/paper-studio/state.json      ← 由本插件读写
```

## state.json 契约

| 字段 | 类型 | 含义 |
|---|---|---|
| `sealed` | boolean | **默认 true（用户模式/封闭）**。读不到文件、JSON 损坏、字段缺失**一律按 true**（失败方向必须安全） |
| `unlock_phrase` | string | 最近一次解锁用的用户原话（留痕，便于复盘"谁在什么时候开的"） |
| `unlocks` | number | 解锁次数（只增，用于观察是否被频繁打开） |

## 纪律

1. **默认封闭**，解锁只能由 `paper_dev action=unlock` + 用户原话触发；**没有任何"自动解锁"路径**。
2. 本目录**只放状态**，不放稿件、不放凭证、不放判据（判据在 `../references/pipeline.json`）。
3. 升级/迁移：本文件是唯一需要保留的状态；删掉即回到"封闭 + 从未解锁"。
4. 环境变量 `DSH_PAPER_HUB` 可改本目录位置（自检与多实例隔离用）。
