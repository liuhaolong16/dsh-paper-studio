# 提示词模板（把风格卡当合同，不当形容词）

> 用法：填好 `[]` 里的内容，把 `style-card.paper-editorial.json` 全文粘在「风格卡」一节。不要删禁止项。

```text
你是前端开发，不是视觉设计师。请严格按下面的「风格卡」实现页面，不得自行发明颜色、圆角、阴影、字号。

## 任务
- 产品：[论文工具 / 具体页面名]
- 主要用户：[作者 / 审稿人 / 学生]
- 用户在这个页面要完成的 3 件事：[1] [2] [3]
- 页面分区（按阅读顺序）：[入口] → [摘要] → [异常/待办] → [明细] → [导出/操作]
- 数据形态：[表格 / 卡片 / 图表]，字段与量纲：[...]

## 风格卡（唯一真源）
```json
[粘贴 style-card.paper-editorial.json 全文]
```

## 硬约束
1. 所有颜色、间距、字号、圆角、阴影只能来自风格卡；不得出现卡外的裸值。
2. 禁止：rounded-*、shadow-*、border-2 及以上、任何渐变、彩色单边强调（border-left/right 彩色、伪元素侧条）。
3. 颜色只用于状态（success/warning/danger/info），且必须同时有文字或图标，不得只靠颜色。
4. 表格必须有 thead、数字列右对齐、容器 overflow:auto；空数据给空态文案。
5. 同类信息必须对齐：标题对标题、数字对数字、表头对内容。
6. 间距只用 4/8/12/16/24/32/48/64 阶梯，不写 13px、17px 这类随手值。

## 交付
- 单文件 HTML（内联 CSS）或 React 组件，二选一，按我指定的技术栈。
- 附一段「用到的 token 清单」，逐项对应风格卡里的键名。
- 不要输出解释性长文；先给可运行代码。

## 自检（交付前逐条回答）
- [ ] 有没有卡外的颜色/圆角/阴影/字号？
- [ ] 有没有彩色单边强调？
- [ ] 表格是否有表头、右对齐数字、滚动容器？
- [ ] 5 秒内能否找到入口、摘要、异常、明细、导出？
```

## 换卡时只改两处

1. `风格卡` 一节整段替换（另一张卡的 JSON）；
2. `硬约束` 第 1–2 条按新卡的 `forbidden` 调整。

其余模板不动。**一个产品同时只允许一张卡生效。**
