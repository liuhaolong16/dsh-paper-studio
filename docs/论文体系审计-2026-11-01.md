## 二、三个决策（给用户的一页）

### A. ARIS 是否上 desktop？

**推荐：暂不上。** 先在 web 拿到 `threadId` + `codex-reply` 续接，再评估 desktop；desktop 是日常面板，`failOnStartupError` 崩不起。触发条件：P-16 完成。

### B. 审稿契约怎么定？

**推荐：方案 2 + manual-review 兜底。** 保留 `glm-5-2`（零成本、非 DeepSeek 家族），但必须显式设 `model_reasoning_effort`（先试 xhigh，被拒降 high），并在审稿记录里标“跨族 + effort”；关键稿走人工跨模型复核。不选 gpt-6-astra（本机无 OpenAI 配额，改了直接不可跑）。

### C. 中文文献腿怎么补？

**推荐：先试方案 2（合法公开源），同时把方案 1 的机构路径写进文档。** 当前实测：CNKI SPA、百度学术验证码，免费源未打通；P-12 保持待办，触发条件=拿到可用公开 API 或学校图书馆权限。不选方案 3（只登记缺口）作为终点。
