## 一句话

结论不是摘要复读，也不是把结果数字再念一遍。视频给了一个**五句话结构**：重申问题+给判断 → 说明意味着什么 → 与别人结论的关系 → 局限 → 下一步。

## 五句话（按视频时间）

1. **重申研究问题 + 直接给主要结论/判断**（约 8–17s）  
   “第一句话就要重申你的研究问题，然后直接给出主要的结论。这一句话不要重复结果了，这是要给出判断。”
2. **说明这个结论意味着什么**（约 17–31s）  
   “结果那部分给的是具体数字，这要回答这些数字说明了什么；你要把你的研究放回到整个研究领域里面。”
3. **说明与别人结论的关系**（约 31–44s）  
   “是支持前面的工作，还是补充了、修正了，还是跟谁的结果不一样；如果不一样，那要说清楚为什么不一致。”
4. **交代局限**（约 44–51s）  
   “哪些条件没有覆盖，哪些问题你还回答不了。”
5. **指出下一步往哪走**（约 51–61s）  
   “这件事还没有解决什么，后面我们还有什么可以做；如果引言部分写过这了，这就不用重复了。”

视频最后说：这样才算把整个结论写完整。

## 机检规则（`bin/conclusion-check.cjs`）

```powershell
node bin/studio.cjs conclusion --file "<稿.md>"
node bin/conclusion-check.cjs --file "<稿.tex>" --json
```

检查项：

| 动作 | 机器判据 |
|---|---|
| ① 问题+判断 | 结论段同时出现研究问题词（本文/本研究/aim…）与结论/发现词 |
| ② 意味着什么 | 出现“意味着/说明/解释/启示/implication/suggest”等，且不是只写“结果表明” |
| ③ 与别人关系 | 出现“一致/支持/补充/修正/不同/差异/相比/consistent/support/extend…” |
| ④ 局限 | 出现“局限/不足/未覆盖/尚未/limitation…” |
| ⑤ 下一步 | 出现“下一步/未来/后续/进一步/future work…” |

另外两条“像摘要”检查：

- 结论段数字 >8 个 ⇒ 警告“像在重复结果”；
- 结论与摘要字符重合度 >0.65 ⇒ 警告“像摘要复读”。

状态：无结论章节或缺 ≥2 个动作 ⇒ `FAIL`；缺 1 个/数字过多/摘要重合 ⇒ `WARN`；全过 ⇒ `PASS`。

## 边界

- 这是**结构启发式**，不判断你的科学结论对不对，也不保证期刊一定接受。
- “支持/补充/修正”必须真的读过前人工作；机检只查有没有这类表述，不验证内容真实性。
- 中英文结论都支持基本关键词；不同期刊的 Conclusion/Discussion 合并写法可能不适用，需人工判断。
- 视频是组会经验分享，不是期刊规范；五句话是写作骨架，不是逐字模板。
