# 写作具体化预检（specificity）

> 本文件解释“知网报告能观测到什么”，以及为什么本插件**不做 AI 检测规避**。
> 工具只检查“长句 / 模板句 / 无证据”的泛化段，帮助把论述写具体；**不预测知网分数，不提供同义词洗稿，不承诺过检测**。

## 0. 红线

`references/pipeline.json` 的 `policy.no_ai_detection_evasion = true`。因此：

- 不提供“降 AI 率 / 过 AIGC 检测”的命令、阈值或提示词；
- 不把“付费测一次”包装成工具能力；
- 不提供同义词替换、洗稿、伪造报告；
- 期刊不要求 AIGC 时，不主动交 AIGC 报告；
- 查重 0% 合法，不必伪造 10%。

本工具的存在理由只有一个：**把泛化论述改成有证据的论述**。这本身是写作质量要求，不是检测对抗。

## 1. 报告可观测到的计分结构（透明化，不是复刻）

### AIGC

```
AI 特征值 = AI 特征字符数 ÷ 总字符数
```

实测（同一篇旧稿/新稿）：

| 稿 | AI 字符 | 总字符 | 报告值 |
|---|---:|---:|---:|
| 旧 | 4 398 | 8 883 | 49.5% |
| 新 | 1 936 | 9 985 | 19.4% |

- 片段是**连续标红区**；“片段字符数”就是该段标红字符数。
- 片段后的百分比是 `该段字符数 ÷ 全文总字符数`，不是段内 AI 率。
- 五个片段相加 = AI 特征字符数。
- 前/中/后 20/60/20 由片段推导，不是独立检测。
- “显著”计入，“疑似”不计入。
- 总字符不是 Word 的“字符数（不计空格）”：新稿 Word 11 988，AIGC 9 985；最接近“正文（不含参考文献、作者信息表）+ 数据表/题注”。
- 参考文献与作者表基本不进分母 ⇒ 加参考文献不能稀释 AIGC。

### 查重

```
总文字复制比 = 重复字符数 ÷ 总字符数
```

两次均 0%，重复字符 0。两次 0% 只能说明没有连续重复串，**无法反推最小匹配长度/数据库**；要有正样本才能测，不建议拿真实投稿做实验。

## 2. 旧→新片段对照（实测）

| 旧 | 字符 | 位置 | 新 | 字符 |
|---|---:|---|---|---:|
| 1 | 1 601 | 英文摘要 + 引言 1.1/1.2 | 中文摘要；1.1 范围 | 317+304 |
| 2 | 730 | 2.3 参考放电识别 | — | 0 |
| 3 | 284 | 3.4 SHAP 归因 | — | 0 |
| 4 | 497 | 4.4 消融 / 5.1 开头 | 5.1 文献关系 | 578 |
| 5 | 1 286 | 5.4 局限 + 5.5 未来 | 5.4 局限；结论 | 384+353 |

净：总字符 +1 102，标红 −2 462；中部降最多（2 476→882），后部次之（1 540→737），前部略降（382→317）。

有效动作（可解释为“信息密度提高”，不是“绕过检测”）：
- 长段拆成“事实—数字—限制”的短段；
- 加失败记录、具体数值、具体文献对比；
- 重写英文摘要；
- 去掉“不是……而是……”“本文要说的是另一层”等对照句式；
- 每条局限后面跟“影响哪个结论/数字”。

无效动作：
- 加参考文献（不进分母）；
- 同义词替换；
- 只删字数不改结构；
- 把局限写成通用清单。

## 3. 工具用法

```bash
node bin/studio.cjs specificity --file "<稿.md|txt|tex>" [--out <报告.md>] [--max 0.20] [--json] [--strict]
node bin/studio.cjs specificity --prompt
node bin/studio.cjs specificity --selftest
```

判据：

1. 长句：平均 >45 字或单句 >70 字；
2. 模板句：≥2 个（“综上所述 / 值得注意的是 / 本文旨在 / 不是…而是… / 不仅…而且… / 随着… / 前者…后者…”）；
3. 无证据：整段没有数字、没有 `[n]`、没有图/表号；
4. 同时命中 ≥2 条，或位于摘要/范围/讨论/局限/结论且命中 ≥1 条 ⇒ **泛化段**。

输出：正文总字符、泛化段字符、泛化段占比、泛化段清单、改写顺序。
**占比只用于排序改写优先级，不是 AIGC 预测值。**

## 4. 改写顺序

1. 先改摘要 / 范围 / 讨论 / 局限 / 结论里的泛化段；
2. 每段补一个实验细节、一个具体对比对象；
3. 拆长句、删模板连接词；
4. 找不到的细节标“待补”，不要编数据。

## 5. 边界

- 知网闭源，AIGC 有随机性，本工具不能保证任何检测结果；
- 本工具不做检测规避；如果目标是“把 AI 率压到某个数”，本插件不提供该能力；
- 真正降低误判的方式是提高信息密度、补证据、补对比，而不是换词；
- 报告不能 PS，同义词洗稿也不被接受。
