## 二、可执行判据（机器可检的那部分 → `bin/figures-kit.cjs --check`）

1. **宽度预算**：单栏 ≤ **85 mm**、双栏 ≤ **170 mm**（超 180 mm 直接判不合格）；SVG 用 `width="…mm"` 声明。
2. **轴标签必须带单位**：至少两条轴标签，且单位以 `(...)`/`[...]` 明确给出（图像型面板用"箭头轴 + 单位"也算）。
3. **色盲安全配色**：只用 Okabe–Ito 安全色板或灰阶/黑白；**出现任意其它彩色 hex ⇒ 不合格**。
4. **禁 chartjunk**：禁**渐变**（`linearGradient`/`radialGradient`）、禁 `filter`（发光/阴影）、禁 3D；装饰性网格线一律去掉。
5. **印刷最小字号**：`font-size` **不得小于 6**（建议 7–9）；面板字母与坐标数字不小于轴标题的 0.8 倍。
6. **色彩映射必须自带色条**：凡用连续色映射，必须有一个**色条**并写明**量名 + 单位 + 数值刻度**；共享一个，不逐格重复。
7. **可比性**：小图矩阵内**同一坐标范围/投影/色彩标尺**；每格要有**标识标题**，并给**标量读数（带单位）**。
8. **矢量优先**：交付优先 SVG/PDF；位图线稿 ≥ 600 dpi、半色调 ≥ 300 dpi。
9. **直接标注优于图例**：序列 ≤ 4 条时优先贴标注；类目图例框只在需要反复对照时使用，并放在面板空白处。

## 三、我方可生成的模板（自研 · `bin/figures-kit.cjs`）

| kind | 用途 | 关键结构 |
|---|---|---|
| `line` | 单栏折线 + 不确定带 | 轴标签带单位 · 安全色板 · 可选色条 |
| `panels` | 小图矩阵（n×m） | 逐格轴标签 · 一致字母位 · 每格标量读数 |
| `bars` | 类目对比 + 误差棒 | 直接标注 · 数值刻度 · 单栏/双栏 |
| `scatter` | 散点 + 拟合 + 置信带 | 轴标签带单位 · 图例或直标 |
| `flow` | 门链/流程图 | 断言式节点标题 · 单向箭头 · 无阴影 |
| `kymo` | 图像型面板（时空图） | **箭头轴 + 单位** · 色条带量名 · 跨面板时间窗括号 |

> 生成即自检：每张模板都由 `--check` 按上表九条判据复核；**不达标的模板不允许交付**。
