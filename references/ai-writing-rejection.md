## 一句话

AI 写论文最容易被一眼拒的，不是“语言不学术”，而是两个结构性问题：**防御性废话太多** 与 **跳跃性写作**。两者看似矛盾（一个太多、一个太少），根因是同一个：模型按概率续写，没有“证据 → 推理 → 结论”的链条。

## 问题 1：防御性废话多

**视频原话**（约 10–31s）：

- “一个就是防御性废话多……简单来说就是废话太多了。”
- 举例：写“天气变冷了”，AI 会写“他在没有生病、没有失血过多、也没有在室内开空调的情况下，突然加衣服，可能是由于天气降温了。”
- “就在写论文的时候，论文里写了一大堆……看不见的观点。”

**机检特征**：

- 高频套话：`值得注意的是 / 众所周知 / 不难发现 / 综上所述 / 显而易见 / 事实上 / 实际上`
- 模糊限定过密：`可能 / 或许 / 也许 / 似乎 / 大概 / 往往 / 通常`（每千字超过阈值）
- 相邻句重复/同义扩写：把一句话换词说两遍
- 用常识、天气、生活流程等“正确但无信息量”的句子撑篇幅

**为什么会被拒**：审稿人看不到你的判断，只看到大量安全、可替换的句子；论文的“信息密度”低。

## 问题 2：跳跃性写作

**视频原话**（约 31–50s）：

- “第二个问题叫跳跃性写作，就是它写得太少了。”
- “在论证你的科学问题的时候，缺乏必要的推理步骤。”
- 举例：写“过年回家路程”，人知道要“走到公交站 → 坐公交 → 坐车 → 到家”；AI 可能只写“我出门了，我坐车了，我到家了”，把中间步骤全省掉。

**机检特征**：

- 因果连接词（`因此 / 所以 / 由此可见 / 这表明 / 这说明 / 证明了 / 显然`）所在句及其前一句都没有证据（数字、百分比、引用、图表、实验/样本/数据）
- 绝对化/强结论（`首次 / 前所未有 / 显著优于 / 大幅提升 / 完全证明`）没有引用或数据
- 段落从“背景”直接跳到“结论”，中间没有“证据 → 推理”的桥

**为什么会被拒**：审稿人无法复核你的推理链，也无法判断结论是否被数据支持。

## 根因（视频约 53–78s）

> “AI 是一个以概率生成文字的大模型……它决定下一个 token 怎么打，是在一定规范下的概率学决定的。所以当它下结论的时候，它会尽可能地排除掉其他的概率……它没有严密的那种推理逻辑，而是通过概率来决定原因和结果。”

对科研这种创新性很高的问题，概率续写会同时造成：

- 不敢下结论 → 用废话和限定词拖长；
- 直接给结论 → 省略中间推理步骤。

## 对策（视频约 79–118s）

### 1. 给足三类可信证据

视频明确说“科研圈值得信任的可靠证据尤其只有三种”：

1. **你自己的数据**；
2. **别人发表在文献里的数据**；
3. **写这篇论文的你，对科学问题的见解、研究品味、学术审美**。

把这三类证据喂给 AI，让它在此基础上做判断和推理，而不是让它自由发挥。

### 2. 人工识别两类问题并改

> “其他解决方式就是，你尽量去识别这两种问题，然后自己手动改。这是 AI 最大最大的缺点……其他的 AI 产生的问题都是比较好改的了。”

即：AI 可以起草，但**“有没有废话 / 有没有跳步”必须由作者逐段识别**；这两类问题不能靠“再生成一遍”解决。

## 落到 paper-studio 的机检

新增 `bin/ai-writing-check.cjs`（`studio ai-writing`）：

```powershell
node bin/studio.cjs ai-writing --file "<稿.md>"
node bin/ai-writing-check.cjs --file "<稿.tex>" --json
```

- 输出：`PASS / WARN / FAIL` + 废话命中、重复句、跳跃结论、模糊限定密度；
- `FAIL` 条件（启发式）：跳跃 ≥2 处，或 废话+重复 ≥5 处，或 模糊限定 >12/千字；
- 边界：这是**启发式机检**，不是语义审稿；命中项必须人工复核，不能替代 reviewer。

## 与现有门的关系

| 现有能力 | 管什么 | 与本文的分工 |
|---|---|---|
| `stylecheck` | AI 味词表、句式 | 管“像不像 AI”；本文管“结构上是否被拒” |
| `number-consistency` | 数字前后一致 | 管数字不漂；本文管“结论有没有证据” |
| `claim-anchor` | 正文主张与出处 | 管引用可追溯；本文管“推理链是否跳步” |
| `ai-writing-check` | 废话/跳跃 | 新增的两类硬伤机检 |

## 诚实边界

- 视频是**经验分享**，不是对照实验；阈值是工程启发式，不是期刊标准。
- “废话”与“必要背景”边界模糊，机检只提示，最终由作者判断。
- 视频没有给出可量化的“拒稿率”，本文也不编造。
