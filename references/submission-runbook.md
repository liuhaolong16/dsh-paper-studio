# 投稿执行 Runbook · v1（2026-10-16 首次实测：JoES / Elsevier 新门户）

> 来源：2026-10-16 论文 A（NASA 电池 SOH）投 *Journal of Energy Storage* 的真实过程（浏览器实机操作 + 提交后回读确认页与列表页）。
> 定位：只管**投稿执行阶段**——把已冻结、门已全绿的成品件安全送进投稿系统，并留下可核对的凭据。
> 稿件内容与机器门由 `references/pipeline.json` 管；投稿件打包由 `_stage-submission.py` 管。

## 0. 适用边界

- 适用：成品件已冻结后的在线投稿（Elsevier / Springer / PLOS / 其他 Editorial Manager 系）。
- 不适用：稿件内容修改（回链路）、投稿件打包（回打包脚本）。

## 1. 提交前（机器做一半，作者做一半）

| 步骤 | 谁做 | 判据 |
|---|---|---|
| 期刊契约逐条对表 | 机器 | `node _journal-contract.cjs --draft <稿.md> --contract _refs/journal-contract-<刊>.json`；**没有被检查 ≠ 通过** |
| 机器门全绿 | 机器 | 默认口径与 `--all` 口径两组读数都留档 |
| 账号与 ORCID | 作者 | 通讯作者账号；**ORCID**（EM 系与 PLOS 系都要，登记进账号资料） |
| 作者信息核对 | 作者 | 英文姓名拼写 · 单位（院系 / 城市 / 省 / 国家）· 通讯邮箱 |
| 声明准备 | 作者 | 竞争利益 · CRediT · 伦理 · 数据可得性（按刊要求） |

## 2. 提交中（AI 可代操作；两类**不代点**）

1. 上传件按上传清单逐件上传；**SI 必须单独上传**（退修高发原因）。
2. 元数据：标题、摘要、关键词、作者顺序、文章类型。
3. **人工边界（不代点）**：① 法律 / 伦理 attestation（声明勾选 + `Complete your submission`）由**作者本人**点（不可逆 + 责任归属）；② 密码 / 验证码**不由 AI 接触**——AI 把光标放到输入框，由用户在浏览器里自己敲。
4. 向导每一步点完**立即回读该步状态**，不靠"操作成功"这类字样。

## 3. 提交后（必做：这是"真提交"的唯一证据）

1. **回读确认页**：抓 `Submitted` 时间、期刊、文章类型、标题、通讯作者姓名与邮箱（页面标题通常即 `Your manuscript has now been submitted`）。
2. **回读列表页**：抓状态（如 `Submission Received via Ingest`）。
3. **落盘「投稿执行记录」**：追加到该稿的 `投稿前检查表` 末尾（时间 / 门户 URL / 状态 / 待核实项 / 下一步），并**备份原检查表**。
4. **两件必须留作"未核实"的事**（未核实 ⇒ 不勾）：① 附件是否逐件上传；② SI 是否随稿上传——新门户不显示附件清单，只能在 EM 或确认邮件里复核。
5. **稿号**：确认页通常**不给**，须等 ingest 完成后从 EM 或确认邮件取（形如 `EST-D-26-XXXXX`）。**未取到前不得编造、不得假填占位**。

## 4. 陷阱清单（全部来自真实事故）

1. **两套入口的认知陷阱**：投递在新门户（`submit.elsevier.com`），跟踪在 Editorial Manager（`editorialmanager.com/<code>`）。EM 页顶可能写 `Site under development. Do not use for live manuscript submission.` —— **不代表这次投递失败**，别因此重复投稿。
2. **"点了"不等于提交**：一切以回读到的确认页 / 列表页为准。
3. **稿号不在确认页**：见 §3.5。
4. **英文界面必须附中文翻译**（用户硬要求）：表单标签、声明条款、报错信息一律原文 + 译文；法律 / 费用类逐条对应、不漏项。
5. **门户页可能不列附件**：别把"页面没显示"当成"没上传"，也别当成"已上传"——标为未核实，去 EM 查。
6. **抓页面被 SSRF 守卫挡**（`web_fetch` 对 `steamcommunity` / `raw.githubusercontent` 报 non-public IP）⇒ 换**真实浏览器**（chrome-devtools MCP）操作与回读。
7. **PowerShell 变量大小写不敏感**：`$A` 与 `$a` 是同一个变量——用 `$pathA` / `$au` 这类带前缀的名字，否则路径变量会被循环内赋值静默覆盖（真实事故：连报一串假"路径不存在"）。
8. **不把"未核实"写成"已完成"**：检查表里未核实的项保持未勾，并写明"为什么要等、去哪查"。

## 5. 交付形态

- 该稿检查表新增一节：`## 投稿执行记录（YYYY-MM-DD）`（五要素：时间 / 门户 URL / 状态 / 待核实 / 下一步）。
- 稿号到位后回填检查表与投稿包清单；投稿状态变化（With Editor → Under Review → Decision）同样按此节追加。
