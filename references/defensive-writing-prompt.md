## 逐字提示词

```text
你是学术写作编辑，请检查我下面这篇论文，找出其中的防御性写作，逐条给出修改意见。
一、处理这四类
1 先扬后抑
给出结论后，立刻用“但是”“然而”“尽管如此”“需要指出的是”转折弱化。
2 限定堆叠
同一句里出现两个以上：可能 / 或许 / 在一定程度上 / 某种程度上 / 倾向于 / 似乎。
3 模糊免责
用“有待进一步研究”“值得深入探讨”“具有重要意义”“为后续工作提供了思路”代替具体结论。
4 扩大局限
把不属于研究范围的问题写成局限，或把一条局限扩写成多条，导致结论强度被自己压掉。
二、每条按这个格式输出
原句 → 问题类型 → 修改建议
三、判断标准只做
删掉限定词后，这句话是否成立？
成立就删，不成立，说明它是有用的边界，保留。
四、这些不作
1 样本量、实验条件、适用对象等真实边界
2 数据本身的不确定性表述
3 数字、引用、公式，一个字都不许改
4 不要把结论加强到证据支撑不了的程度
5 最后给我一个统计
四类各几处，删改后全文字数变化，以及哪几条是你判断后决定保留的，为什么保留。
只改语言，不加新内容。不要替我编造新结果，只基于我提供的内容检查。
```

## 怎么用

```powershell
# 直接打印原提示词，复制给写作模型
node bin/studio.cjs ai-writing --prompt

# 或从 ai-prescreen 的四步提示词里取（已嵌入同一段原文）
node bin/studio.cjs ai-prescreen --prompts
```

注意：视频标题说“3 种”，但提示词实际列了 **4 类**（先扬后抑 / 限定堆叠 / 模糊免责 / 扩大局限）。以画面里的提示词为准。

## 视频里的判断标准（提示词第三条）

- 删掉限定词后句子**成立** → 限定词是废话，删。
- 删掉后**不成立** → 它是有用的边界（样本量、实验条件、适用对象、数据不确定性），保留。
- 数字、引用、公式一个字都不许改；不要把结论加强到证据支撑不了的程度。

## 与机检的关系

`ai-writing-check.cjs` 会标出四类候选：

- 先扬后抑（同句转折弱化）
- 限定堆叠（一句 ≥2 个限定词）
- 模糊免责（“有待进一步研究/值得深入探讨/具有重要意义/为后续工作提供了思路”等）
- 扩大局限（局限段“未/不/无法/缺乏/仅/尚未”条目 >3）

机检只是候选；**删不删按原提示词的判断标准**：删掉限定词后是否成立。真实边界必须保留。

## 边界

- 提示词来自视频画面，逐字抄录；不保证作者授权转载，内部使用。
- 视频是经验分享，不是期刊规范；“有意义/有价值”这类词在部分学科是合理表述，是否算“模糊免责”要人工判断。
- 机检阈值是启发式，不能替代作者对边界与结论强度的判断。
