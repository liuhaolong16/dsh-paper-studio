## 0. 国内 vs 国外：判断线（按**规则体系**，不按语言）

| 维度 | 国内中文刊 | 国外英文刊 |
|---|---|---|
| 投稿入口 | 期刊官网租赁/自建采编系统（知网腾云 `*.cbpt.cnki.net` · 玛格泰克 `*.journalx.cn`+`*author.manuscriptcloud.com` · 勤云 `e-tiller.com`）；**多数明令不收纸质与 E-mail 投稿** | EM / ScholarOne / 出版社门户（Elsevier `submit.elsevier.com` 等） |
| 首屏结构 | **固定书写顺序**（见 §2），中英文摘要**信息对等**，必须有**中图分类号 + 文献标志码** | Title page → Abstract → 正文 → References；无中图分类号 |
| 参考文献 | **GB/T 7714—2025**（顺序编码制；**2026-07-01 起施行**，此前为 2015 版） | Vancouver / APA 等（如 PLOS 用 Vancouver） |
| 作者数著录 | **责任者超 3 人只著录前 3 人，后加「，等」** | 前 6 位作者 + et al.（Vancouver） |
| 表格 | **三线表**（多数硬性） | 无三线表概念 |
| 图 | 常要求**单独原图（如 ≥3 MB 的 .jpg）**，图上不加题注 | 单独文件 + 尺寸/分辨率硬规格（PLOS：TIFF/EPS、789–2250 px） |
| 国内特有 | **著作权转让协议（全体作者签 + 常需单位盖章）· 发表申请单/介绍信 · 利益冲突声明 ·（部分刊）保密审查** | 声明在系统内勾选（attestation）；Funding/Competing 填系统 |
| 查重 | 编辑部多用**万方/知网**，常见阈值**重复率 >15% 退稿** | iThenticate 为主 |
| 一稿多投 | 明令禁止；逾期未复可自行处理（例：2 个月/6 个月） | 同样禁止 |

## 2. 国内刊**标准书写顺序**与量化硬项

**书写顺序（多刊一致的 12 段）** —— 来源：《汉江师范学院学报》来稿须知（2025-05-08）·《河南工业大学学报（自然科学版）》投稿须知（知网 cbimg，2022 存档）：

```
题目 → 作者姓名 → 单位全称 → 所在地名 → 邮编 → 中文摘要 → 中文关键词 → 中图分类号
→ 文献标志码 → 英文题名 → 作者姓名（汉语拼音）→ 单位（英文）→ 英文摘要 → 英文关键词
→ 正文 → 参考文献
（部分刊在正文前另有：作者通讯信息 / 基金项目 / 作者简介；注释置于正文后、参考文献前）
```

| 项 | 常见硬项（两刊实测） |
|---|---|
| 中文题名 | ≤20 字（《推进技术》：一般不超过 20 个汉字） |
| 各级标题 | ≤15 字 |
| 中文摘要 | ≤200 字；**与英文摘要信息对等** |
| 关键词 | **3–5 个**（汉江师范，分号间隔）/ **5–8 个**（河南工大）⇒ **逐刊不同，必须查刊约** |
| 单位著录 | 到**第二级单位、全称**（《推进技术》） |
| 汉语姓名译法 | **姓前名后**；英文题名下**姓氏全大写、名首字母大写**；名两字**中间不空**（如 `ZHANG Xiaoyong`）（河南工大） |
| 图 | 单独原图 ≥3 MB 的 `.jpg`（不含图序图题）；正文内需图序+图题 |
| 表 | **三线表**，表序+表题 |
| 全文 | 例：≤8500 字（汉江师范）；综述/论著各有上限 ⇒ 逐刊查 |
| 注释 | `①②③`，全部置正文后、参考文献前；文内与文后对应 |
| 参考文献 | `[1]` 上标，置于引文所在句/段**标点之前**；同一文献多次引用同一序号 |

### 2.1 ★参考文献：**GB/T 7714—2025**（新版！）

来源：《编辑学报》参考文献著录细则（2026-06-01 发布，**2026-07-01 起严格施行 GB/T 7714—2025** 顺序编码制）。要点：

1. **「参考文献」单列一章并编章序号**（如「5 参考文献」），左顶格排；
2. 研究型论文文献量一般 **≥15 条/篇**；
3. 序号用 `[ ]`；一处引用多篇且序号连续 ⇒ 短横线，如 `[2-3]`；同一文献多次引用**只编 1 个序号**；
4. **多次引用页码不同** ⇒ 页码标在引用处的 `[ ]` **外**，如 `[12]8`；
5. **责任者超 3 人只著录前 3 人，后加「，等」**（← 与英文 Vancouver 的"前 6 位 + et al."是**硬差异**，转换时必须分别处理）。

**十类著录式（《汉江师范学院学报》逐条给出，可作模板）**：连续出版物 `[J]` · 专著 `[M]` · 译著 `[M]` · 论文集 `[A]/[C]` · 学位论文 `[D]` · 报纸 `[N]` · 在线文献 `[EB/OL]` · 技术标准 `[S]` · 技术报告 `[R]` · 专利 `[P]`。

## 3. 国内投稿平台与**逐字操作步骤**

### 3.1 知网腾云 / 协同采编平台（`*.cbpt.cnki.net`）★主流

来源：《腾云期刊采编平台作者操作指南》+《作者投稿操作指南》（知网 publishmedia 官方 PDF，2024-09-26 / 2025-02-18 发布；本机已下载抽文本）。

**作者注册三步**：① 点作者登录页下方【注册】→【注册新用户】→ 按提示**填写账号信息**（含验证）→ ② **完善个人信息**（含验证）→ ③ 注册完成，返回登录入口。

> 官方特别强调两点（**直接影响录用后的刊发与寄刊**）：
> 1. **个人信息、项目信息需与稿件中显示完全一致**，以便正式刊发；
> 2. 电话/地址/邮编务必详细 —— **稿件刊发后按系统登记地址寄送刊物 2 本**。

**投稿两条路径**：**「导航式投稿」**（按步骤分页，有操作提示）· **「一步式投稿」**（步骤尽量集成到极少页面，减少点击）。均从【工作桌面】右侧进入。

**标准七步**（《作者投稿操作指南》原文顺序）：
```
① 先注册再登录 → ② 阅读【投稿须知】→ ③ 上传投稿文件 → ④ 填写稿件基本信息（篇关摘等）
→ ⑤ 填写基金信息（没有则勾选【无基金】）→ ⑥ 填写作者信息
→ ⑦ 推荐/回避审稿人【没有则不填】→ 作者确认投稿 ⇒ 流程结束，编辑端可见并开始审稿
```

**腾云特有的一条硬项**（《腾云…操作指南》原文）：投稿流程中含 **「下载著作权转让协议 → 填写 → 在下一个流程上传」**，且 **「原稿全文和著作权转让协议必传」** ⇒ **不传协议走不完投稿**。

### 3.2 玛格泰克（Magtech）

- 期刊站 `*.journalx.cn`；**办公系统分角色登录**：作者/专家/编委/编辑/主编，**作者端在 `*author.manuscriptcloud.com`**；
- 已取一手样本：《空军航空医学》同行评议政策（2026-05-07）——见 §5；
- **作者端 URL 形态（实测）**：玛格泰克作者登录入口为 `…/journalx/authorLogOn.action?mag_Id=<编号>`（专家/编委/编辑同构，仅 action 不同）。判据：见到 `journalx/` 即玛格泰克系，投稿步骤看「阅读须知 → 上传文件 → 填基本信息 → 基金 → 作者 → 推荐审稿人」同一套。
- **系统故障兜底**：该刊明确"如不能正常投稿请联系编辑部并**将稿件以附件发编辑部邮箱**"（⇒ 国内刊并非一律拒邮箱，**例外写在刊约里**，不要自行假设）。

## 4. 国内刊**特有材料**（国外刊没有这一栏，最易漏）

来源：①《空军航空医学》下载中心（2026）——明列三份模板：**版权转让协议 · 发表论文申请单（模板）· 作者利益冲突公开声明**；②《著作权转让协议》**真实样张**（知网 cbimg 存档，已下载抽文本）。

**协议真实条款要点（样张原文归纳，可作"要签什么"的清单）**：
- 抬头三要素：**论文题目 · 作者（依序排列）· 投稿期刊**；
- 作者保证**原创、不涉密、不一稿多投**，侵权或泄密**责任由作者承担**；
- **全体作者同意**将复制权/发行权/信息网络传播权/表演权/翻译权/汇编权/改编权等**在全世界范围内转让**给编辑部；
- 保证**署名无争议**，署名争议责任自负；
- 录用后**第一作者与通讯作者的部分个人信息（出生年份、职称、邮箱等）默认授权刊登**；
- 申诉类文书（如《申诉意见书》）**须单位盖章后生效**。

> **判据化**：国内刊投稿清单固定加一栏「**盖章/签署类材料**」，状态只能三选一：`已签署上传 / 待单位盖章 / 该刊不需要` —— **不允许留白**。

## 5. 审稿流程与规则（国内常态）

样本：《空军航空医学》同行评议政策（2026-05-07，HTTP 200 已取全文）·《推进技术》投稿指南（学术不端惩罚条款）。

| 环节 | 规则 |
|---|---|
| 查重 | **万方检测，重复率 >15% 退稿**（逐刊不同） |
| 初审 | 编辑部审原创性/科学性/范畴，不通过直接退稿 |
| 外审 | **双盲**：隐去作者姓名，送 **2 名**高级职称（含副高）/博士专家 |
| 修改 | 须**逐条回复**，并把修改处**用不同颜色或下划线标出** |
| 终审 | 主编终审：录用 / 修改后再审 / 退稿 |
| 编委投稿 | 同样走全流程；**编委不得评审本人及家属/同事稿件** |
| 时间窗 | 例：6 个月无录用意见 ⇒ 作者可自行处理；**修改稿逾期 1 个月未回 ⇒ 视作自动撤稿**；审稿周期例：约 2 个月 |
| **一稿多投惩罚** | 《推进技术》：一经发现 ⇒ 取消该稿发表资格 + **两年内不接受该稿第一作者投稿**；已有部分内容投他刊/已发表须**附复印件并说明** |
| 更正/撤稿 | 科学性错误发更正；造假/抄袭/重复发表查实后**撤稿并声明** |

## 9. 第三方站 vs 官方域：识别判据（2026-10-16 实测所得）

**为什么单列一节**：中文期刊检索常**先命中第三方站**，而这些站往往承载着看起来很正规的「投稿须知」「征稿启事」。若直接采信，就会把**代理站的自述**当成期刊要求写进清单 —— 本插件边界早已规定「不采信商业中介」，本节把它落成可执行判据。

**实测样本（同日三条）**

| 站点 | 自述 / 证据 | 判定 |
|---|---|---|
| `tynxb.llyj.net`（称《太阳能学报》杂志社） | 页内**原文**：「严正声明：本站**非期刊官网，非中介代理**。本站仅提供学术规范服务：学术不端检测，AIGC检测，期刊论文排版，学位论文排版，参考文献校准，内容审校，稿件智审，引文一致性审校，推荐合适的期刊投稿…**不代投/不代发/不代写**」+ 咨询电话/微信 | **第三方服务站**（自我声明非官网）⇒ 其「投稿须知 / 期刊简介」只能当**线索**，须标「第三方口径，待核」 |
| `dyjszz.llyj.net/xuzhi/`（称《电源技术》投稿须知） | **同一域名 `llyj.net` 同时挂两本不同期刊**的首页/须知/联系方式 | **代理、服务站家族的强特征**（一域多刊）⇒ 同上，不作官方依据 |
| `ntps.epri.sgcc.com.cn`（《新型电力系统》，中国电科院域） | 两次导航超时（10s / 45s reload） | **官方域**，但本机**通道受限** ⇒ 记「待换通路」，**不判站点不可用**（与 `pcsee.org` 的 DNS 层失败区分开） |

**判据（按优先级）**

1. **先认域**：官方域通常是 `*.edu.cn`、`*.ac.cn`、主办单位机构域（如 `*.epri.sgcc.com.cn`）、期刊自建域（如 `xb.*`）或知网采编平台（`*.cbpt.cnki.net`）；**一域多刊**、域名为**服务/代理**语义（如 `llyj`、`ndhx`）先存疑。
2. **读页内的自我声明**：正规第三方站常自述「非官网、非代理」—— **这句话本身就是排除它作官方依据的凭据**（本轮已把原文入库）。
3. **看是否只卖服务**：检测 / 查重 / AIGC / 排版 / 审校 / 推荐期刊 + 微信电话 ⇒ 商业服务属性；**其转载的「须知」可能是真的，但必须回官方复核**。
4. **回官方复核的通路**（本机实测可用排序）：期刊官方域 → 主办单位官网 → 知网采编平台页 → 刊印信息（版权页 / CN / ISSN）。**任何第三方数字一律标「第三方口径」。**
5. **失败要分型**：`DNS 解析失败`（如 `pcsee.org`，浏览器同样 `ERR_NAME_NOT_RESOLVED`）＝**域名层**问题；**导航/连接超时**（如 `ntps.epri.sgcc.com.cn`）＝**通道层**问题。**两者都不得写成「站点不可用」**，只写「本机未取到 + 通路类型」。

**顺带得到的一条实务发现（对写作阶段有直接后果）**

- 《电源技术》（第三方转载口径）把**使用 AI 辅助写作直接定为学术不端**，并给出量化阈值：**AI 检测总体 AI 率 ≤10%、局部 ≤20%，超则不予送审**；同时要求**查重 <10%**。
- 这与**国外刊**的通行方向**相反**（如 Elsevier 要求**声明** AI 使用范围、PLOS 要求如实披露）。⇒ **同一份稿子投中外刊，AI 相关策略必须分开**：投中文刊前先做 AIGC 自查、把 AI 生成成分压到阈值内；投外刊则如实声明。**本条以第三方口径记入待核，但方向性风险已是实打实。**
