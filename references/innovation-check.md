# 创新点开工前体检（innovation pre-check）

> 来源：B 站视频《如何快速判断你的创新点是否值得做？》（BV1N9xv65EGf，UP：三岁就很皮66，2026-10-30，114 秒；本机 faster-whisper 转写，转写原文见 `D:\DeepSeek\_tmp\bili_BV1N9xv65EGf.txt`）。视频后半段在推广某工具，这里只取**可迁移的判据**，不依赖任何特定产品。

## 一句话

**动手前先证明「没人做过」或「有人做过但有一条空白分支」；证明不了，就不是创新点，是风险。**

## 五步

1. **拆模块，不要整题检索。** 把想法拆成「研究问题 / 方法 / 评价指标 / 应用场景」四块，每块单独列检索式。整题搜一次，跨领域的同名工作会被漏掉。
2. **分头查、交叉问。** 每块至少查 3 个来源（中文库 / 英文库 / 预印本或专利），记录：库名、检索式、日期、命中数。
3. **重合必须落到证据。** 说「已被发表」就给 DOI/URL；说「没被发表」就给检索式与日期。**没有检索记录的「空白」不算空白。**
4. **看引用图的分支方向，不看连线密度。** 周围连线密 ≠ 不能做：
   - 大部分工作挤在「主杆」（如实验室小试的活性指标）；
   - 旁边往「工业放大 / 耐久性 / 实际工况」的分支若几乎没人做，就是切口；
   - 判据是**上游/下游分支往哪走**，不是节点多少。
5. **先写 kill 判据，再开题。** 明确「出现什么证据我就放弃/转向」，避免做半年才发现三十年前有人做过。

## 风险分级（写进选题评估）

| 等级 | 含义 | 处理 |
|---|---|---|
| 红 | 核心模块已被同题发表，且无差异化分支 | 不选；换题或换分支 |
| 黄 | 部分重合 / 主杆拥挤，但存在空白分支 | 可选，必须在评估里写明分支与证据 |
| 绿 | 未发现同题工作，且检索记录完整 | 可选，仍需 kill 判据 |

## 机器可检项（paper-studio `longform --topic-audit`）

- 至少 3 个候选，每个候选有「风险等级 / 模块拆解 / 引用图谱分支 / 可行性 / kill 判据」；
- 全表检索记录 ≥3 条，每条含 `数据库=`、`检索式=`、`日期=`；
- 选中项必须有 `选题：候选N`，且**不能是红色**；
- 声称「空白/未发表」时，必须有检索记录支撑；声称「重合」时必须有 DOI/URL 或明确的「未发现重合」；
- 缺任一项 ⇒ 退出码 1，longform `--check` 同样阻断。

## 与已有门的关系

- `prereg-claim` 管「正文里声称 pre-registered 必须有登记证据」；本检查管「选题阶段声称新/空白必须有检索证据」，两者同一原则：**声称即举证**。
- 期刊模板门管交付格式；本检查管「值不值得做」，发生在 Phase 0，早于写作。
